## 🚀 Tech Stack

- **Framework:** Next.js 15.1.3 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **CMS:** Decap CMS (Git-based)
- **Animations:** GSAP
- **Deployment:** Vercel
- **Package Manager:** pnpm
